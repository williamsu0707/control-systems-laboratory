## 1. Objective

Investigate how the **System Type Number** (number of open-loop poles at the origin $s = 0$) governs the steady-state tracking error $e_{ss}$ of unity-feedback control systems subjected to polynomial reference inputs (Step, Ramp, and Parabolic trajectories), and compare theoretical Final Value Theorem predictions against analog hardware and Simulink simulations.

---

## 2. Theoretical Framework

For a unity-feedback system with open-loop transfer function $G(s)$, the error signal is $E(s) = R(s) - C(s) = \frac{R(s)}{1 + G(s)}$. Provided the closed-loop system is stable, the steady-state error is given by the Final Value Theorem:

$$e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} s E(s) = \lim_{s \to 0} \frac{s R(s)}{1 + G(s)}$$

Defining the static error constants:
* **Position Error Constant**: $K_p = \lim_{s \to 0} G(s)$
* **Velocity Error Constant**: $K_v = \lim_{s \to 0} s G(s)$
* **Acceleration Error Constant**: $K_a = \lim_{s \to 0} s^2 G(s)$

| System Type | Open-Loop Plant Implemented in Lab | Step Input $r(t) = u(t)$ | Ramp Input $r(t) = t\,u(t)$ | Parabolic Input $r(t) = \frac{1}{2}t^2 u(t)$ |
| :--- | :--- | :---: | :---: | :---: |
| **Type 0** | $G(s) = \dfrac{100}{s + 100}$ | $e_{ss} = \dfrac{1}{1 + K_p} = \dfrac{1}{2}$ | $\infty$ | $\infty$ |
| **Type 1** | $G(s) = \dfrac{100}{s(s + 100)}$ | $0$ | $e_{ss} = \dfrac{1}{K_v} = 1$ | $\infty$ |
| **Type 2** | $G(s) = \dfrac{100(s + 1)}{s^2(s + 10)} = \dfrac{100s + 100}{s^3 + 10s^2}$ | $0$ | $0$ | $e_{ss} = \dfrac{1}{K_a} = \dfrac{1}{10}$ |

---

## 3. Experimental Setup & Procedure

1. **Type 0 System**: Configured `CM08` with $T\text{ jumper} = \times 10$ and $a = 10, b = 10$ (without the internal integrator $1/s$ in the loop), yielding $G(s) = \frac{100}{s+100}$. Reference input generated by `CM10` ($0.1\text{ Hz}, 1\text{ V}$). Measured reference $r(t)$ and error output $e(t)$ at `CM01`.
2. **Type 1 System**: Included the `CM08` integrator stage in series, yielding $G(s) = \frac{100}{s(s+100)}$. Evaluated Step, Ramp, and Parabolic inputs.
3. **Type 2 System**: Cascaded two integrators (`CM06-1` and `CM06-2`) with phase-lead compensator `CM09` ($T\text{ jumper} = \times 1, z = 1, p = 10$) to stabilize the double-integrator loop, forming $G(s) = \frac{100s + 100}{s^3 + 10s^2}$, driven at $0.05\text{ Hz}, 1\text{ V}$.

---

## 4. Key Experimental Findings

* **Type 0 Verification**: Under a step input, a constant non-zero steady-state error is observed on both the oscilloscope and Simulink. Under ramp and parabolic inputs, the error signal grows unboundedly because the plant lacks an integrator to accumulate steady-state control effort.
* **Type 1 Verification**: The single open-loop pole at $s=0$ drives the step steady-state error strictly to zero ($e_{ss} = 0$) and tracks a ramp input with a constant finite lag ($e_{ss} = 1/K_v$), while still diverging under a parabolic input.
* **Type 2 Verification**: With two open-loop poles at the origin and lead compensation (`CM09`) for closed-loop stability, the system achieves zero steady-state error for both step and ramp inputs, and maintains a small bounded steady-state error ($e_{ss} = 1/K_a$) under parabolic acceleration inputs.
* **Design Takeaway**: Tracking rapidly varying or higher-order polynomial trajectories requires a higher System Type Number (more open-loop integrators), which reduces steady-state tracking error at the expense of phase lag that must be compensated (e.g., via a zero as in `CM09`) to preserve transient stability.
